# not-hesaplama
📱 Baro-BT Studios - Not Hesaplama

Öğrenciler ve öğretmenler için geliştirilmiş, not hesaplamayı kolaylaştıran pratik bir Android uygulaması.

✨ Özellikler

· Genel Not Hesaplama: Tüm derslerin notlarını girerek genel ortalamanızı görün.
· Tek Ders Ortalaması: Belirli bir dersin sınav ve sözlü notlarını hesaplayın.
· Dönem Sonu (Karne): Dönem sonu karne notunuzu ve durumunuzu öğrenin.
· Yıl Sonu Ortalaması: Yıl sonu genel başarı ortalamanızı hesaplayın.

🚀 İndir ve Kur

Uygulamanın en son sürümünü indirmek için sağ taraftaki Releases sekmesini kullanabilirsiniz.
👉 En Son Sürümü İndir (Releases Sayfası) (Buradaki linki kendi deponun linkiyle değiştirmeyi unutma!)

🛠️ Kurulum (Geliştiriciler İçin)

Projeyi kendi bilgisayarınızda çalıştırmak isterseniz:

1. Bu depoyu klonlayın: git clone https://github.com/baroBT/not-hesaplama.git
2. Projeyi Android Studio ile açın.
3. Gradle build işleminin bitmesini bekleyip uygulamayı çalıştırın.
